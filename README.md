# Yammer Analytics

Учебный проект по анализу данных социальной корпоративной сети Yammer. Набор данных предназначен для практики SQL и аналитического мышления на реальных по структуре, но синтетических данных.

## Цели проекта

Проект повторяет аналитические кейсы Yammer из курса SQL Analytics Training:

- найти причину падения пользовательской вовлеченности;
- оценить использование поиска и понять, какие изменения продукта нужны;
- проверить корректность результатов A/B-теста;
- сформулировать рекомендации на основе данных.

В Yammer вовлеченность определяется как наличие хотя бы одного события типа `engagement`. Основной показатель для кейса о падении вовлеченности — число уникальных пользователей с таким событием за выбранный период.

## Связи между таблицами

Поле `user_id` используется для связи `users.csv` с `events.csv`, `emails.csv` и `experiments.csv`.

Поле `occurred_at` позволяет анализировать динамику показателей во времени. Для расчета вовлеченности следует учитывать уникальных пользователей, а не общее число событий: один пользователь может совершить много действий за период.

## Примеры аналитических вопросов

1. В какие даты или недели началось падение числа вовлеченных пользователей?
2. Связано ли падение с конкретной страной, устройством, типом пользователя или компанией?
3. Изменилось ли поведение пользователей: входы, просмотры, сообщения, лайки или поиск?
4. Есть ли связь между email-рассылками и возвращением пользователей в продукт?
5. Равномерно ли распределены пользователи между группами A/B-теста?
6. Отличаются ли вовлеченность и конверсия между экспериментальными группами?

## Быстрый старт

CSV можно загрузить в любую СУБД или анализировать с помощью Python и pandas. Например, для поиска числа вовлеченных пользователей по дням:

```sql
SELECT
    DATE(occurred_at) AS activity_date,
    COUNT(DISTINCT user_id) AS engaged_users
FROM events
WHERE event_type = 'engagement'
GROUP BY DATE(occurred_at)
ORDER BY activity_date;
```

Для анализа недельных периодов удобно использовать диапазоны дат и `COUNT(DISTINCT user_id)`. При интерпретации результатов важно отделять количество действий от количества пользователей.

## Примечания

- `events1.csv`, `events2.csv` и `events3.csv` — исходные части таблицы событий.
- [`events.csv`](yammer/events.csv) содержит их объединенную версию с одним заголовком и предназначен для основного анализа.
- Данные являются учебными и не отражают реальные данные Yammer.
